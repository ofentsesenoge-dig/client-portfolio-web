About

I'm a Bachelor of Computer and Application Development student at IIE Varsity College, currently interning at FOCI Group in Pretoria. My day-to-day covers API testing, regression testing, k6 load testing and backend validation on a compliance-focused proptech platform.

Alongside work, I build my own full stack projects: a farm-management app in React and Node, a secure authentication portal on ASP.NET Core Identity, and a WPF desktop app with sentiment detection. Being on the testing side of a real platform makes me write code with failure cases in mind.

Outside of code I'm a U23 South African Cross Triathlon Champion competing nationally and internationally. Training and racing at that level is where my discipline and consistency come from.
